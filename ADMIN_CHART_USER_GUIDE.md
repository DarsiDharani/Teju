# Admin Report Charts - User Guide

## Quick Start Guide for Admin Users

### Accessing Report Charts

1. **Login** to the system as an Admin
2. Navigate to the **Admin Dashboard**
3. Look for the **"Generate Reports & Analytics"** button (usually with a chart icon)
4. Click the button to open the Reports Modal

### Viewing Charts

#### Step 1: Select a Report Type
Choose from the available report cards:
- 📊 **Users Overview** - User distribution and roles
- 📚 **Training Performance** - Completion rates and popularity
- 💬 **Feedback Analysis** - Response rates and trends
- 🎓 **Skills Gap Analysis** - Competency gaps and targets
- 📈 **System Analytics** - Usage patterns and activity
- 📄 **Complete Report** - Excel export only (no charts)

#### Step 2: View Charts
- Click the **"View Charts"** button
- A new modal opens with:
  - Key metrics at the top
  - Interactive chart in the center
  - Additional data tables below

#### Step 3: Switch Chart Types
Look for the chart type buttons above the chart:
- 🥧 **Pie** - Circular chart showing proportions
- 📊 **Bar** - Vertical bars for comparison
- 📈 **Line** - Trend line over time
- 🍩 **Doughnut** - Pie chart with center hole

Click any button to instantly switch the visualization style!

### Chart Types by Report

| Report Type | Available Chart Types |
|-------------|----------------------|
| Users Overview | Pie, Bar, Doughnut |
| Training Performance | Bar, Pie, Line |
| Feedback Analysis | Line, Bar, Pie |
| Skills Gap Analysis | Pie, Doughnut, Bar |
| System Analytics | Doughnut, Pie, Bar |

### Downloading Charts

#### Download as Image
1. While viewing a chart, click the **"Download"** button next to the chart
2. Chart will be saved as a PNG image
3. Filename includes report type and timestamp
4. Perfect for presentations and reports

#### Download as Excel
1. Click the **"Download Excel"** button at the bottom of the modal
2. Comprehensive Excel file will be generated
3. Contains multiple sheets with detailed data
4. Professional formatting with color-coded headers

### Understanding the Charts

#### Users Overview Report

**Pie Chart Shows:**
- Blue slice: Managers
- Green slice: Employees  
- Orange slice: Trainers

**Key Metrics:**
- Total users in system
- Breakdown by role
- Trainer percentage

**Additional Data:**
- User registration trend by month

#### Training Performance Report

**Bar Chart Shows:**
- Each bar represents a department
- Height shows number of trainings
- Compare departments at a glance

**Key Metrics:**
- Total trainings
- Assignment counts
- Attendance rates
- Overall completion percentage

**Additional Data:**
- Top 10 trainings by enrollment
- Completion rates per training

#### Feedback Analysis Report

**Line Chart Shows:**
- Feedback submissions over time
- Identify trends and patterns
- Spot peak feedback periods

**Key Metrics:**
- Total feedback submissions
- Response rate percentage
- Unique trainings with feedback

**Additional Data:**
- Top trainings by feedback count

#### Skills Gap Analysis Report

**Pie Chart Shows:**
- Green slice: Skills Met (targets achieved)
- Red slice: Skills with Gap (needs improvement)

**Key Metrics:**
- Total skills tracked
- Gap percentage
- Number of skills met vs gap

**Additional Data:**
- Top skills with highest gaps
- Expertise level distribution (Current vs Target)

#### System Analytics Report

**Doughnut Chart Shows:**
- Orange: Pending requests
- Green: Approved requests
- Red: Rejected requests

**Key Metrics:**
- Total system requests
- Total submissions
- Breakdown by status

### Tips for Best Results

✅ **Do's:**
- Use **Pie/Doughnut** charts for 3-6 categories
- Use **Bar** charts when comparing departments or categories
- Use **Line** charts for time-based trends
- Download charts before closing modal
- Review metrics summary for quick insights

❌ **Don'ts:**
- Don't use pie charts with too many categories (hard to read)
- Don't use line charts for non-time-based data
- Don't close modal without downloading if you need the chart

### Chart Reading Tips

**Pie/Doughnut Charts:**
- Larger slice = Higher proportion
- Hover over slice to see exact value
- Colors help distinguish categories
- Legend shows what each color represents

**Bar Charts:**
- Taller bar = Higher value
- Easy to compare exact values
- Great for rankings
- Hover to see precise numbers

**Line Charts:**
- Upward trend = Increase over time
- Downward trend = Decrease over time
- Flat line = Stable period
- Sharp changes indicate significant events

### Troubleshooting

**Chart not showing?**
- Wait for loading spinner to complete
- Refresh the page and try again
- Check your internet connection
- Contact IT support if problem persists

**Chart looks wrong?**
- Try switching to a different chart type
- Clear your browser cache
- Use a modern browser (Chrome, Firefox, Edge, Safari)

**Download not working?**
- Check browser's download settings
- Allow pop-ups from this site
- Ensure you have storage space
- Try a different browser

### Best Practices for Presentations

1. **Choose the Right Chart Type**
   - Pie for composition (what makes up the whole)
   - Bar for comparison (which is bigger/smaller)
   - Line for trends (how things change)

2. **Export at Right Time**
   - Download charts when data is fresh
   - Take screenshots if needed for documentation
   - Save Excel files for detailed analysis

3. **Combine Visualizations**
   - Use multiple chart types for same data
   - Show overview with pie, details with table
   - Export different views for comprehensive reports
